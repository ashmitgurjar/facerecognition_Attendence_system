# Face Recognition Attendance System

A Face Recognition Attendance System that automates attendance tracking using computer vision and facial recognition technology. The system detects and recognizes faces in real time, marks attendance automatically, and stores records for efficient management.

## Features

* Real-time face detection and recognition
* Automatic attendance marking
* Student/employee registration
* Attendance record management
* Secure and accurate identification
* User-friendly interface
* Attendance data storage and retrieval

## Technologies Used

* Python
* OpenCV
* Face Recognition Library
* NumPy
* Pandas
* SQLite/MySQL (if applicable)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/facerecognition_attendance_system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd facerecognition_attendance_system
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## Usage

1. Register users by capturing facial images.
2. Train the recognition model.
3. Start the attendance system.
4. The system will detect recognized faces and mark attendance automatically.
5. View attendance records in the generated database or CSV file.
